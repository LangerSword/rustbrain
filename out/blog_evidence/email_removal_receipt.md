# Emails found in the vendored tree, and removed

Captured 2026-10-19, before and after the removal commit. Counts come from git
against the pre-removal HEAD, so they are reproducible from that commit; the
after-state is the working tree at the removal commit.

## Before

    $ git ls-tree -r --name-only HEAD data/upstream/team/people | wc -l
    683   (people TOMLs, each with name/github/email/IDs)
    $ git grep -l 'email' HEAD -- data/upstream/team/people | wc -l
    542  (of those files carried an email field)
    $ git grep -l '@' HEAD -- data/upstream/team/teams | wc -l
    55  (team TOMLs with an address somewhere)
    $ git grep -c '@' HEAD -- data/upstream/team/teams | awk -F: '{s+=$NF} END {print s}'
    180 (address lines: lists, extra-emails, some personal addresses in archived working groups)
    $ git diff --cached --name-only --diff-filter=D | grep -v 'team/people/' | wc -l
    109 (upstream source, tests, docs, workflows: removed because they carry example and bot addresses and the product never reads them)

## What replaced the people tree

    data/upstream/team/people_handles.txt: 683 handles, one per line, sorted.
    No names, no emails, no github-id, no discord-id, no zulip-id. Generated by
    scripts/fetch_upstream.py at fetch time: each people TOML is read in memory and
    only its `github` field is kept. State of other fields kept: none.

## After

    $ git grep -nIE '[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}'
    (no output: zero matches in the tracked tree)

    $ grep -rnE '^\s*(email|address|extra-emails)\s*=|\"(email|contact)\"\s*:' data/
    (no output: no contact keys in data/)

## Words that remain, and why they are not addresses

- `data/snapshot.json`: team slugs `foundation-email-redirects` and `rustconf-emails`,
  and a successor note saying the foundation hosted its emails.
- `data/upstream/team/teams/foundation-email-redirects.toml` and
  `teams/rustconf-emails.toml`: the same slugs and their comments.
- `data/upstream/team/people_handles.txt`: the header line that says no emails are
  written.
- `PINS.md`, `README.md`, `scripts/build_snapshot.py`, `scripts/fetch_upstream.py`:
  the policy prose that states the rule.

None of these carries an address. The word "contact" also appears in archived team
comments (for example `teams/archive/wg-rustfix.toml`); it is prose, not a field.
