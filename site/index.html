an rfc lands on the right desk, or the tool says why it cannot.

what it refuses to do.

  • it does not guess a rename: an archived team is mapped only when its own file records a successor, quoted with file and line;
  • it does not return an empty table: a label with no active team is reported as a true gap, by name;
  • it does not sort reviewers by volume alone: latest activity leads, because counting alone routes to people who left years ago.

what it is not.

there is no model anywhere in the path, and rust is a foundation, not a company: element eight of the brief scores zero, and the method page says so in the first sentence.

three pages in this site are the honest part: the gaps, the limits, and the bugs i found in my own findings.
