method and limits

rust is a foundation, not a company. that is element eight, scored zero, by nature.

two pinned public revisions, one deterministic ingest, one graph, and every number on this site re-derivable from the committed snapshot. nothing here is a model's opinion; all of it is a function's output.

the pipeline

  • scripts/fetch_upstream.py and scripts/fetch_rfcs.py pull the two trees at the pinned shas; contact fields are stripped in memory, never written;
  • scripts/build_snapshot.py builds data/snapshot.json deterministically, with a content hash over its own body; --check fails on any drift, on either the file or the rebuild;
  • scripts/verify_snapshot.py re-parses every vendored team file with an independent toml parser and compares roster counts;
  • scripts/load_graph.py loads snapshot into the pinned falkordb module (ver 42201); scripts/test_queries.py asserts 41 results including direction flips;
  • scripts/export_site_data.py writes the site's data.json; scripts/assert_site_numbers.py re-derives every number it carries and fails on any mismatch.

limits, plainly

  • element 8 is zero. rust is a foundation: no revenue, no customer, no contract, no reporting line anywhere in this data. the funded roles that do appear are named by upstream itself (program managers, hired via the foundation; the crates.io on-call team, "composed of employees of the Rust Foundation"), and team leads hold peer authority, not managerial authority. this is not an org chart.
  • the successor map is curated, not parsed. four entries, each with a cited file and line; of the 52 archived files, exactly 4 carry a note and all 4 are mapped, 3 are listed unmapped with a reason each, 45 carry none. the map covers what upstream documents and claims nothing more.
  • volunteer teams, not an org chart; subteam relations are recorded, reporting lines do not exist in the data.
  • handles only. the snapshot and the graph carry no names, emails, avatars or rfc bodies; this site shows handles only. the vendored trees ship with contact fields stripped, and history was purged of the addresses that once sat in the vendored people tree (receipt).
  • titles are truncated to 120 characters and document bodies are never stored.
  • no llm anywhere in the path. an ai assistant wrote the code at the entrant's direction; every number was produced by running the commands in the repository.
