the corrections are the honest part

five bugs this project found in its own findings.

each entry links to the receipt in the repository's evidence folder. none of them was fixed by changing the story; all of them were fixed by changing the measurement.

1. the query-direction mistake

an early version of the ingest wrote edges in one direction and the queries asked in the other. cypher returns zero rows with no error for a pattern that matches nothing, so the bug looked like a correct empty answer. i measured two correct results, drew a wrong conclusion about the engine, wrote it down, and had to retract it. the receipt reproduces both forms on a throwaway graph: outbound 1 row, inbound 0, unlabelled inbound 1 row with bindings swapped.

receipt: direction_receipt.txt. what survived is a rule: every known-good query must assert a non-zero row count.

2. 35 orphans, then 385, then 83, then three definitions

the orphan figure moved three times: 35 of a 111-rfc sample; 385 of 761 measured while the roster silently missed the archived teams; 83 mislabelled as "no membership and no alumni" when it was the merge-labelled subset of the 385. corrected today, each with its own definition: 381 of 761 authors are absent from every active team's roster, 169 have no team file and no alumni record, 41 of those carried a merge label.

receipts: 20_orphan_figure_correction.md, 16_kill_test.md.

3. the depth-1 walk that missed 52 archived files

the first roster read teams/*.toml and never looked in teams/archive/, which holds 52 more files, including libs-api and core; some authors looked like orphans who were not. the same builder also let an empty members list swallow the next list (18 alumni counted as 18 members) and counted role names as handles. an independent toml parser caught two of the three; the third needed a second check that hashes the file on disk.

receipt: 01_snapshot_bugs.md. four bugs in one builder, each with the failing case recorded.

4. the clock drift

hours-left arithmetic ran off the local clock, and a network check against three independent servers during the build put the same instant 2 hours 40 minutes past the stated window. one curl would have caught it earlier; the receipt keeps the three responses.

receipt: clock_drift_receipt.txt.

5. the pinned sha that drifted anyway

pins.md said one team revision; the snapshot, the committed tree and the build script said another. hashing a single team file at both revisions settled which was true, and the fix made pins.md generated, never hand-written: a ci job regenerates it and fails on any diff. the red run that proves the gate shows the exact drift line.

receipt: pins_drift_receipt.md.

two rules that survived all five

  • a query that matches nothing returns zero rows with no error: assert a non-zero count for every known-good query, and run the flipped form expecting zero;
  • every number gets its definition and its denominator in the same sentence, and the sentence is generated by a script, not typed by a person.

the full evidence index, including what is still to capture, is out/blog_evidence/INDEX.md.
